# Arabic Social Media Analytics Dashboard

A 4-page interactive Power BI dashboard analyzing Arabic-language social media performance across platforms, content categories, and post types. This end-to-end analytics workflow was built during Week 2 of the Advanced Data Analytics Internship with the National Telecommunication Institute (NTI) in collaboration with ITIDA.

### 🛠️ Tech Stack & Tools
* **Microsoft Power BI:** Dashboard design, interactive visuals, and UI navigation
* **Power Query:** Data cleaning and transformation of messy raw datasets
* **Data Modeling:** Star-schema design (Fact and Dimension tables) with a dedicated Date Table
* **DAX (Data Analysis Expressions):** Time-intelligence and performance metrics

## 🔍 Key Features & Workflow

* **Data Engineering & Modeling:** Extracted and cleaned a large Arabic-language dataset using Power Query. Structured the data into a robust star-schema model with active relationships to support cross-filtering.
* **Advanced DAX Measures:** Developed custom metrics to track performance, including:
  * Total Likes, Comments, Shares, Reach, and Impressions
  * Overall Engagement Rate & Average Engagement Rate per Post
  * Month-over-Month (MoM) Likes Growth
  * Year-over-Year (YoY) Engagement Growth
  * Sponsored vs. Organic Engagement comparisons
* **Interactive UI/UX:** Designed a multi-page report featuring navigation buttons, KPI cards, custom slicers, and a detailed performance summary matrix.

## 💡 Business Questions Answered
The dashboard is designed to provide actionable marketing insights by answering practical questions:
* 📌 Which platform has the highest average engagement rate?
* 📌 Which content category performs best with the target audience?
* 📌 Which day of the week generates the highest average reach?
* 📌 Which post type (video, image, text) drives stronger engagement?
* 📌 How consistent is posting activity and audience growth across different months?
